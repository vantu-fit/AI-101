# AI-101

An English learning outline for AI, starting with **large language models (LLMs)**.

Start with the [six-stage LLM roadmap](llm/README.md). The path assumes solid programming and machine-learning foundations; review prerequisites only when needed.

## Learning objectives

- Explain how an LLM learns from data and generates text.
- Understand the roles of model architecture, context, data, and adaptation.
- Interpret evaluation results and recognize misleading comparisons.
- Understand how inference and retrieval fit into a useful LLM application.
